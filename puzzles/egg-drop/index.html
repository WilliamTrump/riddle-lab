The Egg Drop

A new museum has a Fabergé egg on each floor of a 100-story building, each one worth more than the one below. A thief will drop one out of a window into her truck, and wants the most valuable egg that won't break.

  • She has two replica eggs to test with. A broken replica is gone for good.
  • An egg survives a drop from any floor up to some highest safe floor, and breaks from any floor above it.

What's the fewest drops that always finds the highest safe floor, wherever it is?

      Hints

      1. Start with one egg. Once it breaks, it's gone, so she has to go up one floor at a time. That can take 100 drops.

      2. With two eggs, use the first to jump ahead and the second to check floor by floor inside the gap where the first one broke. Every 10th floor takes up to 19 drops. Try the Every 10th floor example and test it.

      3. The gaps don't have to be equal. Each jump with the first egg has already used up a drop, so make each gap one floor smaller than the last. With 10 floors: drop at 4, then 7, then 9.

      4. If the first gap is n floors and each gap after it is one smaller, the gaps cover n + (n−1) + … + 1 = n(n+1)/2 floors. The smallest n that reaches 100 is 14 (14 × 15 / 2 = 105).

        So drop the first egg from floors 14, 27, 39, 50, 60, 69, 77, 84, 90, 95, 99 and 100. When it breaks, go up floor by floor from just above the last safe floor with the second egg. Whatever the floor, that takes at most 14 drops, and no plan can promise fewer.
